About the 8-Puzzle

The 8-Puzzle is a state-space search problem consisting of eight numbered tiles and one blank space arranged in a 3 × 3 grid. A legal move swaps the blank with one adjacent tile. This application finds the lowest-cost solution path using the A* informed search algorithm.

Select either Manhattan Distance or Misplaced Tiles as the heuristic function, then run A* to observe the search process and final path.

About A* Search

Description

A* is an informed best-first search algorithm that combines the cost already spent with an estimate of the remaining cost.

Working Principle

A* repeatedly expands the node with smallest \(f(n)=g(n)+h(n)\), where \(g(n)\) is path cost and \(h(n)\) is a heuristic estimate.

Advantages

It is complete and optimal when using an admissible, consistent heuristic. A good heuristic reduces unnecessary expansions.

Limitations

A* can consume substantial memory because it stores states in its frontier and explored set, especially for difficult puzzles.

Misplaced Tiles

Counts numbered tiles that are not in their goal positions. The blank tile is not counted.

Manhattan Distance

Adds the horizontal and vertical distance of every numbered tile from its goal position. The blank tile is not counted.
